# Бег Жеки


iPhone-приложение для бега.

## Возможности v4

- GPS-трекинг дистанции
- живая линия маршрута на Apple Map
- текущий и средний темп
- время и скорость
- пауза / продолжение / финиш
- история тренировок
- свайп вправо для карты маршрута
- голосовой тренер на русском после каждого километра
- работа GPS в фоне при заблокированном экране / свернутом приложении
- Bluetooth-аудио для голосовых подсказок

## Важно для фоновой работы

В Xcode должны быть включены Background Modes → Location updates и Audio.
В приложении запрашивается Always Location access, потому что беговая сессия должна продолжать записываться при блокировке экрана.

iOS может ограничивать работу приложения, если пользователь принудительно завершит его свайпом вверх из App Switcher.

## Сборка

Откройте `Бег Жеки.xcodeproj` в Xcode, выберите свою Team в Signing & Capabilities и установите приложение на физический iPhone.

Рекомендуется тестировать GPS и фоновые режимы именно на физическом устройстве.


### v5 — целевой темп
- Целевой темп по умолчанию: **5:00/км**.
- Можно выбрать цель от 3:00 до 10:55/км.
- Голосовой тренер предупреждает, если текущий темп отклоняется от цели более чем на 15 секунд/км.
- Предупреждения ограничены одним разом в минуту.
- На каждом километре остаётся стандартный отчёт о дистанции, темпе и времени.
